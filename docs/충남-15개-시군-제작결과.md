## SEO·콘텐츠·탐색

대표와 각 상세 페이지에 고유 Title·Description·H1·OG, self canonical을 적용합니다. 상세의 BreadcrumbList·Service는 실제 페이지 URL과 충청남도 시·군 이름에 맞추고 FAQPage는 실제 화면과 같은 원본을 사용합니다. 대표 페이지는 BreadcrumbList와 FAQPage를 사용합니다. 검색 순위나 FAQ 리치 결과를 보장하지 않습니다.

시·군별 정보성 본문과 FAQ는 서로 다른 실제 학습 점검을 안내합니다. 공통 학년·과목·서비스 안내는 유지하면서 지역명만 치환한 학습 글을 만들지 않았습니다. 대표→15개 시군, 상세→충남 대표→전국 안내의 HTML 링크와 기존 학년·과목·방문·화상·상담 링크를 연결했습니다.
