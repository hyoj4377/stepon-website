## 미확인 항목

공식 울산시 사이트와 GitHub Pages 공개 URL은 일반 요청과 권한 확장 재시도 모두 실행 환경의 CONNECT 프록시 403으로 차단되었습니다. 대상 사이트의 실제 HTTP 403을 확인한 것이 아닙니다. 세부 동네 소속·행정경계의 공식 원문 대조, 공개 배포 완료·실제 공개 HTTP 응답, 네이버 수집·구글 색인은 미확인입니다. 동네 카드는 상담 생활권 안내이며 전체 행정동이나 세부 경계 안내로 표시하지 않았습니다. 직접 검증한 공식 출처로 등록하지 않았습니다.

실제 전화 앱 실행·카카오 대화·상담 폼 접수도 미확인입니다. 기존 연결 주소를 유지했으며 테스트 신청은 보내지 않았습니다.
