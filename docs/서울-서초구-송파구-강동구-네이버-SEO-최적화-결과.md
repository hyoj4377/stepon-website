## 8. 중복 콘텐츠 검증

**수정 전 검색 성과 기준선 미확보**입니다. Git의 수정 전 콘텐츠 스냅샷과 실제 노출/유입 기준선은 다릅니다. 이번에 순위·검색량·노출 증가·문의 증가를 추정하지 않습니다.

비교 후보는 **강남구**, 추가로 수정하지 않은 **마포구·양천구**입니다. 모두 실제 서울 상세 페이지이고 초중고·평가/학습 정보와 동일한 공통 기술 기반이 있어 구조상 비교 후보로 선정했습니다. 실제 검색 성과·검색량·경쟁도가 같다는 의미는 아닙니다. 강남구는 그대로 유지합니다.

1. 수정 전 기준선: 확보 가능한 서치어드바이저의 실제 기간·항목과 기존 분석/상담 기록을 수집합니다. 과거 데이터가 없으면 미확보 상태를 유지하고 임의 복원하지 않습니다.
2. 실제 배포: 커밋/푸시 성공과 GitHub Pages 공개 응답/제목 반영 확인을 구분해 기록합니다.
3. 네이버 반영: 검색 결과의 실제 URL·표시 제목·영역·광고 포함 기준을 기록합니다. 커밋 시각을 재수집 시각으로 사용하지 않습니다.
4. 검색 반영 확인 후 2주: PC/모바일·검색어·로그인/지역·시간대·결과 영역 조건을 고정해 노출/순위를 반복 관찰합니다. 통합 영역의 순서와 웹문서 영역 순위를 구분합니다.
5. 반영 후 4주: 같은 요일 구성/조건으로 클릭·노출과 가능한 유입/상담을 비교합니다. 수집 지연이나 표본 부족이면 관찰을 연장합니다. 배포/반영 시점이 미확인이므로 임의의 달력 날짜를 확정하지 않습니다.

서치어드바이저에서 실제 제공되는 검색 성과만 기록하고 모든 URL×검색어 조합·임의 기간·평균 순위가 제공된다고 가정하지 않습니다. 페이지 유입은 별도 도구, 상담 버튼 클릭은 기존 추적 체계, 실제 상담은 운영 기록이 있는 경우에만 측정합니다. 버튼 클릭은 상담 완료가 아니며 이번에 추적 스크립트를 신규 추가하지 않았습니다. 학기/시험/방학·경쟁 문서·사이트 전체 변경 등 교란 요인을 기록하고 이번 동시 문구 변경에서 개별 요소의 효과를 분리해 단정하지 않습니다.
