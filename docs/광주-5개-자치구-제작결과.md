## 미확인 항목

공식 광주광역시 사이트 접근은 일반 요청과 권한 확장 재시도 모두 CONNECT 프록시 403으로 차단되었습니다. 세부 행정동 경계와 각 동네 소속의 외부 공식 원문 대조는 미확인입니다. 페이지의 동네 목록은 상담 생활권 안내이며 전체 행정동 목록이나 경계 설명으로 표시하지 않았습니다. 검증한 공식 출처인 것처럼 등록하지 않았습니다.

공개 사이트 접속도 실행 환경 프록시 차단으로 확인되지 않았습니다. 이는 GitHub Pages가 반환한 HTTP 403이 아닙니다. 공개 배포 완료·실제 공개 HTTP 응답·네이버 수집·구글 색인은 미확인입니다. 로컬 성공과 공개 사이트 확인을 구분합니다. 전화 앱 실행·카카오 실제 대화·상담 폼 접수는 실제 사용자 기기에서 확인해야 하며 테스트 신청을 보내지 않았습니다.
