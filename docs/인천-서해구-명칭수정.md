# 인천 서구 → 서해구 명칭 수정

## 근거와 확인 범위

운영자가 인천광역시 공식 자료와 서해구 경계 FAQ를 확인한 결과로 제공한 **2026년 7월 1일 시행, 종전 인천 서구 남부는 서해구로 명칭 변경·북부는 검단구로 분리** 내용을 근거로 반영했습니다.

- https://www.incheon.go.kr/IC01070101
- https://www.seohae.go.kr/open_content/main/open_info/boundary/faq.jsp

실행 환경에서는 공식 사이트 원문을 직접 열람하지 못했습니다. 사용자 제공 확인과 도구로 직접 검증한 사실을 구분하며 원본 데이터의 검수 메모에도 이를 기록했습니다.

## 변경 범위

- `data/seo/regions.json`: 인천 대표 목록·현재 구 명칭을 쓰는 FAQ·설명, `incheon-seo`의 name·official_name·Title·Description·H1·본문·FAQ·서비스·CTA 명칭 수정. 개편 전 이름을 설명하는 '종전 서구' 표기는 유지.
- `regions/incheon/index.html`, `regions/incheon/seo/index.html`: 위 원본에서 재생성. Open Graph·BreadcrumbList·Service·FAQPage도 해당 표시 내용과 일치.
- `data/seo/generated.json`: 변경된 두 HTML 해시 갱신.
- `tests/test_seo.py`: 인천 11개 구·군 예상 명칭 수정, 서해구 명칭·기존 URL·관할 목록 분리·부산/대구 서구 유지 회귀 검사 추가.
- 본 보고서.

공통 CSS·JS·템플릿·디자인·상담 연결·인증 파일은 수정하지 않았습니다.

## URL 및 색인 보호

공개 경로와 canonical은 다음 기존 URL을 유지합니다.

https://hyoj4377.github.io/stepon-website/regions/incheon/seo/

내부 ID `incheon-seo`와 slug `seo`도 유지합니다. 명칭 수정만으로 URL 이동·리디렉션을 만들 필요가 없으며 기존 접근 주소를 보존합니다. `sitemap.xml`은 기존 파일과 바이트 단위로 동일하고 전체 78개 URL, 인천 12개 URL을 유지합니다.

## 동네 목록 검토

현재 서해구 페이지의 청라동·가정동·석남동·가좌동·신현동·연희동·검암동·경서동·공촌동·심곡동 10개 목록과 검단구의 원당동·당하동·마전동·불로동·왕길동·대곡동·금곡동·오류동 8개 목록은 겹치지 않습니다. 따라서 검단구로 이전한 항목은 없습니다. 이는 기존 목록과 운영자가 제공한 개편 내용에 따른 검토이며 세부 경계의 공식 원문 대조를 완료했다고 주장하지 않습니다.

인천의 다른 10개 상세 페이지는 변경 금지 조건에 따라 그대로 보존했습니다. 검단구 기존 본문의 개편 설명에 남아 있는 '인천 서구와 검단구' 문장도 이 범위 밖이므로 수정하지 않았습니다. 이번에 수정한 대표·서해구 페이지의 현재 구 명칭은 서해구로 통일했습니다.

## 검증

- 관련 자동 테스트 9개 모두 통과(154.189초): 재빌드 재현성·전체 메타정보·전체 내부 링크/앵커·사이트맵·인천 11개·서해구 URL 보존·부산16·대구9·서울25 구조화 데이터 회귀 검사. 전체 44개 테스트 묶음을 재실행한 결과와는 구분합니다.
- 전체 SEO 빌드: 77개 하위 페이지, 사이트맵 78개 URL 생성.
- 생성 파일 비교: 기존 파일 중 인천 대표·서해구 HTML만 변경. 나머지 인천 10개와 서울·부산·대구·학습 안내 HTML은 SHA-256 해시 동일.
- 원본 데이터 비교: `incheon`, `incheon-seo` 레코드만 변경.
- 브라우저: 인천 대표·11개 상세 × 1440/768/390/320px 총 48개 조합에서 로컬 HTTP 200, H1·이미지·전화 링크·상담 링크·앵커 및 가로 넘침 검사 통과.
- PC·모바일 스크린샷 확인, 대표 페이지의 기존 `seo/` 링크를 키보드로 열어 서해구 제목 확인. 모바일 상담 메뉴 펼침·Escape 닫기 통과.
- 외부 상담 링크를 변경하지 않았으며 실제 전화 앱·카카오 대화·상담 신청 접수는 미확인.
