## 구현 및 SEO

- 원본 `data/seo/regions.json`에 대표 페이지와 11개 상세 데이터를 반영했습니다. 기존 공통 생성기를 재사용하며 HTML만 직접 편집하지 않았습니다.
- 전국 지역 안내에서 인천 대표 페이지로, 대표 페이지에서 11개 상세 페이지로 연결합니다. 상세 페이지에는 대표·전국·학년·과목·방문·화상 안내 링크와 기존 상담 연결이 있습니다.
- 고유 Title·Description·H1, canonical·Open Graph, 한국어 lang·viewport를 적용했습니다. 상세 페이지의 BreadcrumbList·Service 지역은 인천광역시 및 해당 구·군이며 FAQPage는 실제 노출 답변과 일치합니다.
- 새 URL 12개를 기존 사이트맵에 추가했습니다. 사이트맵 전체는 중복 없는 78개이며 서울25·부산16·대구9 상세 URL을 유지합니다. 별도 사이트맵은 만들지 않았습니다.
- 상단 로고·메뉴와 기존 전화번호를 사용하는 전화·카카오톡·무료체험 플로팅 상담 메뉴를 공통 디자인 그대로 사용합니다. 메인 배경·수강후기 슬라이더는 변경하지 않았습니다.

## 지역 정보의 확인 범위

제물포구·영종구·검단구를 별도로 구성하고 옛 중구·동구를 현행 독립 구로 중복 생성하지 않았습니다. 강화군·옹진군은 군으로 표기했습니다. 읍·면·동 카드는 상담 생활권 안내이며 행정구역 전체 목록이나 정확한 경계 지도를 의미하지 않습니다. 옛 명칭을 쓰는 경우 현재 도로명주소를 함께 확인하도록 안내합니다.

인천 공식 사이트는 실행 환경의 CONNECT 프록시 403으로 접근하지 못했습니다. 따라서 세부 경계와 동네 소속의 공식 외부 대조는 **미확인**입니다. 출처를 검증한 것으로 기록하지 않았고 `sources`는 비워 두었습니다. 개편 경계에 해당하는 주소는 운영자가 공식 주소·행정구역 자료와 추가 대조해야 합니다.

## 검증

- 자동 테스트: 전체 43개 실행에서 기존 검사 42개 통과. 새 인천 검사 1개는 기대 문구를 실제 본문인 `9개 구`로 정정한 뒤 단독 재실행하여 통과했습니다(1개, 14.335초). 최초 실행은 정정 전 테스트를 이미 메모리에 읽은 상태였습니다. 제품 오류로 인한 실패는 없었으며 최종 소스의 43개 검사 항목을 확인했습니다.
- 빌드: 77개 하위 HTML 생성, 전체 사이트맵 78 URL. 재빌드 검사 통과.
- 브라우저: 대표 1개·상세 11개 × 1440/768/390/320px, 총 48개 조합 통과. 로컬 HTTP 200, H1 1개, 이미지 로딩, 가로 넘침 없음, 전화·외부 상담 링크 존재 및 앵커 대상 확인.
- 대표·상세 페이지의 로컬 내부 링크 268개를 확인했습니다. 키보드로 지역 상세 페이지 이동과 모바일 상담 메뉴 펼침·Escape 닫기 동작도 통과했습니다.
- 기존 지역 원본 데이터는 인천을 제외하고 동일합니다. 기존 생성 파일 중 전국 지역 목록·사이트맵만 바뀌었으며 서울·부산·대구·학습 안내 HTML은 해시 기준 동일합니다.
- 외부 카카오톡·신청 폼의 실제 접수 및 스마트폰 전화 앱 실행은 미확인입니다. 링크 주소를 변경하거나 접수 테스트를 수행하지 않았습니다.

## 공개 배포 및 검색 확인

GitHub Pages 공개 URL 요청은 일반 실행과 권한 확장 재시도 모두 CONNECT 프록시 403으로 차단되었습니다. 이는 대상 사이트가 반환한 HTTP 403이라는 뜻이 아닙니다. 공개 HTTP 응답·GitHub Pages 배포 완료·네이버 수집·구글 색인 상태는 **미확인**입니다. 푸시 후 브라우저에서 대표 및 상세 페이지를 확인하고 기존 사이트맵을 검색엔진 관리 도구에서 다시 확인해 주세요.

## Git 반영

원격 main과 작업 기준 커밋의 일치를 확인한 뒤 커밋·푸시합니다. 최종 커밋 SHA와 실제 푸시 결과는 작업 완료 응답 및 Git 이력에서 확인할 수 있습니다. 문서 자체의 커밋 SHA를 본문에 삽입해 자기 참조 해시를 만들지 않았습니다.
