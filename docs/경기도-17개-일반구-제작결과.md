## 콘텐츠와 SEO

- 17개 페이지에 초등·중등·고등, 국어·영어·수학·사회·과학, 학교 내신·시험 준비·학습 수준·맞춤 계획·자기주도 복습·진도와 취약점 점검을 안내합니다.
- 각 구의 학습 본문·질문을 개별 작성했습니다. 기존 상위 시의 고유 학습 글도 유지했습니다. 확인되지 않은 학교·교육 수요 통계·강사 이력·후기·성과·가격·지점은 추가하지 않았습니다.
- 방문·화상 방식과 기존 전화/카카오/무료체험 링크를 재사용합니다. 실제 방문 배정은 주소·과목·희망 일정에 따라 상담합니다. 새 페이지의 원본·표시 본문·구조화 데이터에는 '1:1' 표현을 새로 넣지 않았습니다. 기존 시·다른 지역의 표현은 수정하지 않았습니다.
- 구별 Title 형식을 검색 의도에 따라 구분하고 고유 Description·H1·self-referencing canonical·Open Graph·한국어 lang·viewport를 적용했습니다. HTML 링크와 논리적 H1/H2/H3 구조를 사용합니다.
- BreadcrumbList는 홈 → 전국 → 경기도 → 해당 시 → 일반구 5단계입니다. Service의 지역은 해당 일반구, 상위는 시와 경기도로 일치시켰습니다. 가짜 주소·가격·평점은 없습니다.
- 구마다 FAQ 5개를 실제 화면과 일치하는 FAQPage로 출력합니다. 교육 서비스의 FAQPage 적용이 Google FAQ 확장 검색결과 노출을 보장하는 것은 아닙니다. Google 공식 가이드 최신 원문의 이번 외부 재조회 여부는 아래 한계와 구분합니다.

## 행정동 소속 대조와 출처

행정동 233건을 공개 보조 데이터의 구별 소속과 대조했습니다. 생활권 그룹에는 실제 행정동 명칭을 별도로 표기하며, 그룹명을 법정동 명칭으로 단정하지 않습니다. 광교는 이 페이지에서 수원 영통구 광교1·2동 기준이며 인접 도시 생활권 전체를 영통구에 속한다고 표현하지 않았습니다. 수정구의 위례도 해당 구의 실제 주소를 확인하도록 했습니다.

- 보조 자료: https://github.com/vuski/admdongkor
- 기준 버전: 20261001
- 사용 커밋: d5d5a821c8de6cc337d47eeca604d7af76271c9b
- 파일: `dist/data/_index_v3.parquet`
- README는 통계청 SGIS 자료를 기반으로 행정동 변경 이력을 반영한다고 설명합니다. **정부기관의 직접 게시물이 아닌 제3자 가공 자료**입니다.
- 검토에 쓴 명칭·코드·기준일·원본 해시는 `data/seo/gyeonggi_borough_geography.json`에 남겼습니다. 시험과 빌드에는 parquet 라이브러리나 외부 API가 필요하지 않습니다.

공식 시청 원문은 외부 프록시 차단으로 직접 열람하지 못했습니다. 위 대조는 명시한 시점의 보조 자료에 대한 확인이며, 작업일 현재의 세부 법적 경계를 공식 확인했다고 주장하지 않습니다. 학교명을 사용하지 않아 미검증 학교급·소재지는 추가하지 않았습니다.

상위 6개 시 데이터에는 `boroughs` 목록과 구별 링크 섹션만 추가했습니다. 기존 시의 Title·Description·H1·canonical·소개·학습 본문·동네 카드·FAQ는 그대로 유지했습니다. 기존 129개 URL은 삭제하지 않았습니다.

- `data/seo/regions.json`: 일반구 17개 및 부모 6개 시의 탐색 데이터

- `scripts/build_seo.py`: 일반구 계층·시 카드·5단계 breadcrumb·상위 시/도 링크 지원
- `regions/gyeonggi/{suwon,yongin,seongnam,goyang,anyang,ansan}/index.html`: 링크 섹션 재생성
- 해당 17개 구 경로의 `index.html`: 신규 생성
- `data/seo/generated.json`: 생성 목록·해시
- `sitemap.xml`: 기존 파일에 17개 URL 추가
- `tests/test_seo.py`: 일반구·소속·URL·메타·링크·JSON-LD·FAQ·게시 경계 회귀 검사. 기존 31개 시군 검사에서 시 하위 일반구를 허용하도록 요구사항 반영

전체 테스트에서 반복되는 동일 준비 빌드는 클래스당 한 번 수행하고 테스트마다 Builder를 깊은 복사해 변이 테스트의 격리를 유지했습니다. 독립 새 빌드를 비교하는 재현성 검사는 유지했습니다. 웹사이트 런타임 의존성·디자인은 바꾸지 않았습니다.

## 배포·외부 확인 및 Search Console 후속 조치

원격 main과 작업 기준이 일치하는지 확인한 뒤 검증된 변경만 커밋·푸시합니다. 최종 SHA와 푸시 여부는 작업 완료 응답 및 Git 이력에 남깁니다.

시청·공개 GitHub Pages·Google FAQ 공식 가이드 요청은 일반 실행과 권한 확장 재시도에서도 실행 환경의 CONNECT 프록시 403으로 차단되었습니다. 이는 대상 서버의 실제 HTTP 403이 아닙니다. **실제 공개 배포 완료·공개 HTTP 응답·Google 최신 가이드 원문 재조회·네이버/Google 색인 상태는 미확인**입니다. 로컬 성공과 공개 사이트 확인을 구분합니다.

푸시 후 GitHub Pages 배포 상태 및 대표 신규 URL을 실제 브라우저에서 확인하고, 기존 `https://hyoj4377.github.io/stepon-website/sitemap.xml`에서 146개 URL이 공개되는지 확인해 주세요. 새 사이트맵을 만들거나 기존 URL을 삭제하지 말고 기존 사이트맵을 Search Console에 재제출한 뒤 마지막 읽은 날짜와 상세 오류를 확인합니다. 사이트맵 '발견 0'을 전체 사이트 색인 0으로 해석하지 않습니다.

실제 스마트폰 전화 앱·카카오 대화·상담 폼 접수는 미확인입니다. 기존 연결 주소를 유지했으며 테스트 신청은 보내지 않았습니다.
