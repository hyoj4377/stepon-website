## 외부 확인의 한계

공식 대전시 사이트와 GitHub Pages 공개 URL은 일반 실행·권한 확장 재시도 모두 실행 환경의 CONNECT 프록시 403으로 차단되었습니다. 이 응답은 대상 사이트가 반환한 HTTP 403이라는 의미가 아닙니다. 세부 동네 소속·행정경계의 공식 원문 대조, 공개 배포 완료와 실제 공개 HTTP 응답, 네이버 수집·구글 색인은 미확인입니다. 동네 카드는 상담 생활권 안내이며 전체 행정동 목록이나 경계 설명이 아닙니다. 검증한 공식 출처로 등록하지 않았습니다.

실제 스마트폰 전화 앱·카카오 대화·상담 폼 접수는 미확인입니다. 기존 연결 주소를 유지했으며 테스트 신청은 전송하지 않았습니다.
