# 1:1 표현 점검 및 반영 기록

- 점검일: 2026-10-19
- 운영자 확인: 방문수업과 화상수업 모두 학생 한 명과 선생님이 수업하는 1:1 형태입니다. `data/seo/site.json`의 `lesson_format`에 확인 범위와 날짜를 기록했습니다. 실제 배정·일정·진행 조건은 기존처럼 개별 상담에서 확인합니다.
- 변경 전 공개 HTML의 본문·제목·메타정보에는 1:1 또는 일대일 표현이 없었습니다. 메인 서비스 소개, 수업 방식·학년·과목 안내, 전국·서울 지역 안내의 주요 설명에 명시가 빠져 있었습니다.
- 전역 금지 설정·프롬프트 템플릿은 없었습니다. `tests/test_seo.py`의 은평구 회귀 테스트에서 1:1이 없어야 한다고 검사하던 항목만 제거했습니다. 존재하지 않는 행정동 검사는 유지했습니다.
- 모든 지역 title·description·H1과 모든 canonical·URL·내부 링크·사이트맵을 유지했습니다. 지역별 기존 문단은 삭제하지 않고 서울 대표·서초·양천·은평의 관련 본문에만 설명을 추가했습니다.
- 방문·화상·영어·수학·국어 안내 title과 주요 8개 서비스·학년·과목 안내 description만 선별 보완했습니다. 모든 H1은 유지했습니다.
- 수행평가 안내 본문은 그대로이며, 관련 안내 카드가 참조하는 영어·수학 등 페이지 제목이 바뀌어 링크 문구도 함께 갱신됩니다.
- 메인은 `index.html`의 소개 문구와 `STEPON_CONFIG.introduction.description`, 안내 페이지는 `data/seo/guides.json`과 `data/seo/regions.json`, 전국 소개는 `scripts/build_seo.py`에서 관리합니다.
- 앞으로도 표현은 페이지의 검색 의도와 실제 수업 형태에 맞춰 사용합니다. 지역명이나 키워드만 바꾼 중복 문구를 일괄 삽입하지 않습니다.
