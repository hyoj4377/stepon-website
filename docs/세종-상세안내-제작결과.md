## 미확인 사항

공식 세종시 사이트와 GitHub Pages 공개 URL은 일반 요청·권한 확장 재시도 모두 실행 환경의 CONNECT 프록시 403으로 차단되었습니다. 이는 대상 사이트가 반환한 실제 HTTP 403이 아닙니다. 세부 동네 소속·행정경계의 공식 원문 대조, 공개 배포 완료·실제 공개 HTTP 응답, 네이버 수집·구글 색인은 미확인입니다. 직접 검증한 공식 출처로 등록하지 않았습니다.

실제 전화 앱 실행·카카오 대화·상담 접수는 미확인입니다. 기존 주소를 유지했고 테스트 신청은 전송하지 않았습니다.
