## 검증

- 전체 SEO 빌드와 재빌드 일치 검사 통과. 공개 서브 페이지 65개, 비공개 시·도 초안 14개 유지.
- 전체 자동 테스트 42개 통과(530.074초). 최종 도입 문장 교정 후 대구 대상 테스트와 빌드 일치 검사를 재확인.
- 상세 9개 × 1440/768/390/320px = 36개 화면 조합, 대표도 동일한 4개 폭에서 로컬 HTTP 200·메타·이미지·FAQ·상담·플로팅·대비·가로 넘침 검증.
- 전국 → 대구 대표 → 상세 왕복, 키보드 Tab/Enter 이동 확인. 대표·수성구·군위군 PC/모바일 화면 확인.
- 기존 서울·부산·학년/과목 안내·메인·공통 스타일의 소스와 HTML 변경 없음. 구글 소유 확인 파일도 유지.
- 공개 HTTP 요청은 프록시 CONNECT 403으로 차단. 실제 GitHub Pages HTTP 200·공개 배포 화면·네이버 수집·구글 색인은 **미확인**. 이를 사이트 자체 HTTP 오류로 판정하지 않음.
- 공식 행정구역 웹 자료를 직접 열람해 최신 관할을 검증했다고 주장하지 않음. 실제 전화 연결·카카오 대화·신청 폼 접수도 미확인.
